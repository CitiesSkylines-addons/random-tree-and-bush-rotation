# Installation

This project targets Cities: Skylines 1 and is based on the local folder `RandomTreeAndBushRotation`.

1. Use the official distribution or the release artifact for this mod.
2. Place the mod folder under the game's `Addons\Mods` directory.
3. Enable the mod in Content Manager → Mods.
4. Install every dependency listed by the upstream project or in the mod's own documentation.
5. Restart the game after installing or updating, then test in a disposable save first.

For third-party projects, do not download or redistribute files from this repository as a substitute for the official upstream source.
